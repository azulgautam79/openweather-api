# Go Weather API

A simple REST API built with Go that fetches current weather data from the OpenWeather API and returns a clean, custom JSON response.

## Features

- Get current weather by city name
- Temperature in Celsius
- Feels-like temperature
- Humidity
- Atmospheric pressure
- Weather condition and description
- Wind speed
- Country code
- JSON API response
- Deployable to Vercel

## Tech Stack

- Go
- OpenWeather API
- Vercel
- `net/http`
- `encoding/json`
